# 个人展示平台

上海杉达学院 · 计算机科学与技术(卓越班)的个人展示主页。

纯静态单页网站,无需任何构建工具或依赖。

## 文件结构

```
Personal_Information/
├── index.html      # 页面结构骨架(挂载点,一般不需要修改)
├── css/style.css   # 样式与主题(配色、布局、动效;想改视觉风格才动它)
├── js/main.js      # 交互逻辑(渲染数据、动效;想改行为才动它)
├── data.js         # ⭐ 所有个人数据都在这里,日常只编辑这个文件
└── README.md       # 本说明文件
```

> **编辑原则**:改内容 → 只动 `data.js`;改外观 → `css/style.css`;改交互 → `js/main.js`。

## 如何编辑

1. 用任意编辑器(VS Code、记事本等)打开 `data.js`
2. 按文件内的中文注释提示,修改以下内容:
   - **基本信息**:姓名、一句话介绍、学校、联系方式(邮箱/GitHub 等)
   - **关于我**:自我介绍,支持多行
   - **技能**:分组展示,可在组内任意增删技能
   - **项目经历**:每个项目是一个卡片,含名称、简介、技术标签、链接;复制一段示例即可新增项目
   - **教育与经历**:时间线形式,记录学业、竞赛、实习等
3. 保存后刷新浏览器即可看到效果

> ⚠️ 注意:编辑 `data.js` 时不要破坏引号、方括号和逗号,否则页面会显示空白。保存后刷新页面,如果浏览器控制台(F12)报 JS 语法错误,检查一下最近改动处的标点。

## 本地预览

直接双击 `index.html` 用浏览器打开即可。

## 发布到 GitHub Pages

1. 将仓库推送到 GitHub
2. 进入仓库 **Settings → Pages**
3. Source 选择 `main` 分支、根目录 `/`,保存
4. 稍等片刻,即可通过 `https://<你的用户名>.github.io/Personal_Information/` 访问
