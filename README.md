# 徐潘磊 · 个人主页 (LtMouse8552)

一个 IDE 编辑器风格的个人作品集 / 简历网站：整个页面被设计成一间「代码编辑器」，包含菜单栏、标签页、主题切换等元素，用终端美学展示个人信息。

## ✨ 特点

- 🖥 **IDE 风格设计**：菜单栏（File / Edit / View / Help）、文件标签页（about.md / skills.json / experience.log / projects/ / contact.sh），完整模拟编辑器体验
- 🌗 **主题切换**：内置 dark+ 等编辑器主题，一键切换明暗
- 🎨 **精致背景层**：网格 + 光斑（orb）+ SVG 噪点纹理 + 鼠标跟随光晕
- ✍️ **等宽字体美学**：JetBrains Mono / Space Grotesk / Inter 字体组合
- 📱 **响应式**：适配桌面与移动端

## 🗂 页面板块

| 标签 | 内容 |
| --- | --- |
| `about.md` | 个人介绍（上海杉达学院计算机科学与技术专业卓越班） |
| `skills.json` | 技能清单（JSON 风格展示） |
| `experience.log` | 经历时间线（日志风格展示） |
| `projects/` | 项目列表 |
| `contact.sh` | 联系方式（脚本风格展示） |

## 🛠 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- Google Fonts（JetBrains Mono / Space Grotesk / Inter）
- 无框架、无构建工具，纯静态页面

## 🚀 使用方式

直接用浏览器打开 `index.html` 即可，也可部署到 GitHub Pages 等任意静态托管服务。

## 📁 目录结构

```
├── index.html      # 页面入口
├── css/style.css   # 样式
├── js/main.js      # 交互逻辑
├── data.js         # 页面数据
```
